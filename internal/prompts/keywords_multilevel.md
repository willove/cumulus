# keywords_multilevel — 多级粒度关键词抽取

从用户查询抽取 1..N 级粒度的检索关键词（N 由配置注入，默认 3）。

## 输入
User Query: "{{query}}"
Levels: {{levels}}

## 输出
只返回一个 JSON 对象：
{
  "level_1": ["最粗/最核心"],
  "level_2": ["中等粒度"],
  "level_3": ["最细/可能的原文用词"]
}

## 规则
- 每层 1–5 个词；层号从粗到细。
- 优先保留领域术语与数字。
- 各层互补不冗余，勿跨层重复；用词贴近目标语料的原文写法。
- 只从查询语境抽取，不要引入外部信息。
- 语言跟随 Query。

## 冻结回归
- 层数 == Levels。
- JSON 可解析。
- level_1 非空（search 类查询）。
