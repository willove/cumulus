# 现状报告：cumulus-next 到哪了（2026-10 端到端复盘）

> 这份报告的每个数字都来自 `scripts/acceptance.sh` 的**真跑**（真模型、真实语料、
> 7 篇文档、两个 realm）。复跑：`DASHSCOPE_API_KEY=… bash scripts/acceptance.sh`。
> **没有数字的结论一律标"未验证"**——这是本项目的规矩：不许拿"应该可以"充数。

## 一句话

**链路是通的**：从摄入到"知识文档 + 选题建议"的闭环在真实使用中站得住（26/26 验收通过），
但**只在"个人知识库"这个规模与形态下**验证过；**多用户、多写入、长期演进**都还没碰。

## 一、已验证（真跑通过）

| 能力 | 证据 | 备注 |
|---|---|---|
| 目录摄入 + 多租户 | alpha realm 7 篇、beta realm 0 篇，隔离断言通过 | watch 用**凭证的 realm**（不是启动参数） |
| 问答（有据时） | 答案带 1 条引用、3 条窗口 | 引用能映射回文档坐标 |
| 诚实拒答 | 语料外问题 `refused=true` | 不硬答 |
| **词汇桥救口语问句** | 「狗在外面拉屎没人管咋办」→ 扩词「犬只户外排便/犬只随地便溺…」→ `bridge=used`、**带引用答出** | 这是桥第一次在真跑里**真的用上** |
| 事件流 | `started` / `content` / `done` 帧齐全，`[DONE]` 收尾 | 进度分母 = 注册 stage 数 |

| 失败路径 | 空主题 400、坏 JSON 400、无证据给可读原因 | 不产出半截文档 |

## 二、复盘抓出的五个真 bug（都已修）

这一节比上一节重要：**验收脚本第一次跑就红了 6 条**，逐个查下去全是真问题。

| # | 症状 | 根因 | 类别 |
|---|---|---|---|
| 1 | health 报 `realm=""`、`corpus_docs=0`（明明 7 篇） | health 读启动参数 `-realm`，不是**凭证推出的 realm** | **说谎的观测面** |
| 2 | 摄入后 `Rebuild` 读 `documents`，而写入在 `documents/default` | 读写的集合口径不一致（测试替身忽略集合，把它盖住了） | 假件掩盖了真 bug |
| 3 | watch 报"+6 docs"，查询却 0 窗口 | watch 重建的是**单数索引**，而请求走 per-realm 缓存 | 可选面按错索引 |
| 4 | `CUMULUS_ZERO_WINDOW_ESCALATE=1` 在 serve 下无效 | 该开关**只有 eval 读**，serve 路径没接线 | 可选面在一个入口没装 |
| 5 | 桥扩词完全正确，加权检索却恒 0 命中 | `WeightedRetrieve` **钉死了启动时的索引**（升级贵路早就修过这个坑，**桥这条腿漏了**），且签名拿不到 realm | 同一教训的遗漏点 + 多租户 |

第 5 条的修法是**改签名**：`WeightedRetrieve` 从 `func(map)` 变成
`func(*context.Context, map)`——多租户下"取哪个索引"取决于**谁在问**，没有 context
就做不到。顺带把桥扩出的词放进 `escalation.bridge_terms`（**排查桥失手的第一手材料**）。

另外修了一个结构问题：升级记录收尾原先"逐字段抄"（先丢结局、再丢扩词，两次都要回来补），
改成**整体取回**——`escalateRetrieve` 之后由它拥有那条记录。

## 三、未验证 / 已知缺口（不粉饰）

| 缺口 | 状态 |
|---|---|
| **护栏 `rejected-score` 的真实拦截率** | 语料上**触发不了**（两个探针上桥都没扩偏）。只有行为测试兜着 |
| **同义改写的差异判定** | 词面口径 + LLM 判据都试过；实测"请求减缓"vs"申请缓缴"仍判不同 → **差异说明偏多报** |
| **会话回放（§5 NOTE）** | 验收里没测到 session（离线合成不建会话）；功能在，但**这条路径本轮没被验到** |
| **决策模型（闸门）** | 早期实测在 DuReader 上**没有证据提升准确率**，现在默认关 |
| **多写入并发** | 只测了单写入者；多客户端同时生成文档/摄入**未测** |
| **长期演进** | 没有"跑一个月语料会不会退化"的观测；`gen-` 文档会随源变化需要重生成（v 号递增） |
| **中文长文档** | 验收语料是短条文（每篇 3 条）；**长文档/多章节未测** |

## 四、怎么复跑

```bash
# 全量（真模型，约 2–4 分钟）
DASHSCOPE_API_KEY=… bash scripts/acceptance.sh

# 离线（不花 LLM 钱；LLM 相关断言会退化为 NOTE）
bash scripts/acceptance.sh --offline

# 门禁（九道）
bash scripts/gates.sh
```

## 五、下一步建议（按"用户能感觉到"排序）

1. **每租户配额与计量**——共享实例的必需品；现在多租户只做了隔离，没做边界；
2. **会话回放路径补一条验收断言**（本轮 NOTE 里唯一的功能性缺口）；
3. 论断的**稳定语义 id**（让差异说明可信）——收益中等，属工程洁癖；
4. 中文长文档的检索表现（需要造一份长文档语料再量）。
