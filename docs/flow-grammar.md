# flow-grammar.md — 流程文法 SSOT

> 状态：v0.1 · 2026-10-07 · 本文件是 cumulus-next 全部流程的单一事实源
> 读者：动 `internal/flow`、`internal/qaflow`、`internal/evalfcore`、`internal/learncore` 之前读本文。实现与本文冲突时，先改实现或先改本文，不允许两处漂移。

## 一、基本对象

| 词 | 含义 | 代码落点 |
|---|---|---|
| **上下文（context）** | 进程内唯一共享状态容器，每个集合/缓存/游标是它上面的一个 key | `internal/context.Context` |
| **命名空间（realm）** | 同一 key 在不同 realm 下解析到不同数据集（多租户） | `context.Realm`，由 `-ns` 传入 |
| **注册（registration）** | 往 context 放东西的唯一动作，必须同时给出逆 | `context.Registration.Release` |
| **提交视图（committed view）** | 一次迁移针对的环境快照，全程不变、可追溯 | `context.CommittedView` |

一次用户可见的处理（问答、评测、学习）是**一次迁移**：开始有目标视图，进行中只认开始时那一套环境，结束后留下提交视图。

## 二、流程一：一次问答（qaflow）

六个 stage，顺序固定。契约四元组：**读什么 / 写什么 / 逆是什么 / 怎么验证**。

| # | stage | 读 | 写 | 逆 | 验证 |
|---|---|---|---|---|---|
| 1 | 意图澄清 | 会话 | 改写 | 丢弃改写 | 改写可逆回原问；排序回到原问 |
| 2 | 证据供给 | 语料 | 证据窗口 | 窗口失效 | 引用可回溯到原文坐标 |
| 3 | 充足性路由 | 证据窗口 | 路由 | 丢弃路由 | 见 §2.1 |
| 3.5 | 升级执行（条件） | 路由 | 证据窗口 + 路由（重判） | 丢弃新窗口与路由 | 见 §2.3；路由非 escalate 时整件空过（留痕） |
| 4 | 合成 | 证据窗口 | 答案 | 丢弃答案 | 见 §2.2 |
| 5 | 记账 | 无 | 用量 | 红字冲销 | token 账平；上游不报 usage 即判成本未知并停止后续调用 |
| 6 | 学习（可选） | 用量 + 痕迹 | 信念 | 回退一版 | 护栏基线比对，掉线即回滚 |

提交视图记四项版本：**语料、配置、检索策略、信念**。

### 2.1 路由规则（stage 3）

升级（FAST→DEEP）或拒答，只允许两类信号触发：

1. **草稿置信度**：首 token 对数概率的指数。只是路由代理，不是正确性裁判，不出现在答案里。
2. **接地检查**：答案或其内容词能否在证据窗口的原文 span 里对上。对不上即弱接地。

决策留痕（信号值、阈值、结论）进路由 key，提交视图可回放“当时为什么升级”。

### 2.3 升级执行（stage 3.5，条件件）

路由判 escalate 时，跑注入的贵路取数（FAST→DEEP 级联），然后**用同一把
尺重判路由**：

- 够了 → fast，带新窗口进合成；
- 仍不足 → refuse（reason 记 "escalation exhausted"）——升级是补救机会，
  不是绕过充足性硬答的旁门；
- 没判 escalate → 整件空过，记 "route did not escalate"；
- 没配贵路 → 死标签，记 "no escalation backend wired"（遥测里可见，
  不许假装升级过）。

升级前后路由判据同一把尺（gatherSignals），贵路是注册件（BM25DeepEvidence
等），换底物不动流程。

### 2.2 合成规则（stage 4）

- 合成只读证据窗口与改写，不私开检索；要检索就退回 stage 3 重新路由。
- 答案里每个断言必须映射到窗口 id；映射不上的断言删除或显式标“无证据”。
- 输出头按任务类型约束格式（选择题/是否题/事实题/列举题各不相同）。

## 三、流程二：一次评测运行（evalfcore）

一次运行 = 一个 episode：

1. **冻结**：题集 sha、语料 sha、配置 sha 受理时定死；运行期间改业务语料不影响已冻结实验。
2. **隔离**：每次运行一个独立引擎实例，灌冻结语料原样；业务集合不写。
3. **登记化**：采集器、判官、对照臂都是可挂可卸的注册；换判官是卸旧注册装新注册，不是改运行器。
4. **原子落盘**：运行状态与逐题结果同一个存储值原子写；被 kill 的运行只报 interrupted，绝不冷启动重放。
5. **可比性**：三指纹不一致即判不可比，只列理由不列差值。

### 失败模式六分类（capture 时归类）

| 类别 | 判据 | 修复方向 |
|---|---|---|
| 底物错配 | 所需证据类型与所用检索类型不同（要实体 grounding 却在文本里翻；要数值测量却在摘要里找） | 换证据源/升级结构化查询 |
| 召回不足 | 正确证据没进候选 | 查摄取、分词、改写 |
| 接地失败 | 答案词在证据窗口对不上 | 查合成约束、引用解码 |
| 路由误判 | 该升没升（漏）或不必要升级（费） | 调 stage 3 两类信号 |
| 腐烂 | 长任务中直接放弃或提前给不确定答案 | 查上下文管理频率、保进展感信息 |
| 超限 | 窗口或轮次打满 | 查驱逐策略、早停条件 |

## 四、流程三：一次学习周期（learncore）

学习 = 一次**受管变更**，五阶段各是一个注册：

1. **观察**：取深遥测（决策、harness 动作、环境状态、结果连成的轨迹，不是只看最终分）。
2. **诊断**：把成本与失败归属到具体组件；失败按 §三 的分类归因，不许“统统算召回问题”。
3. **提议**：只动白名单旋钮，一次假设调用生成。
4. **评估**：冻结评测上对照跑，不过护栏不上线。
5. **提升**：护栏过才切，掉线即回滚，全程落盘。

纪律：只改 harness 运行条件，不改模型权重、业务语料、评测协议。重试 = 新的受管变更，不是原地重放。

## 五、六条不变量

1. **一切经过 context**：共享状态必须绑 key；没绑 key 的位置（游离计数器、隐式全局）是缺陷。
2. **注册必有逆**：给不出逆的注册不进主流程；逆在应用时那一个状态上有效，是作者的义务，runtime 不代保。
3. **依赖显式**：可选组件（信念、词表桥接这类）登记为 Activator，声明 Requires；上下文每次变化后由 context 分类（激活/停用/中性）并驱动转换，状态进 `Components()` 供 status 面——**不许静默失效**（cumulus 的 vocab 桥接撤除、MCS 不触发，死在没有这个分类器）。
4. **迁移有提交视图**：每次处理记录环境版本；不可比时只给理由。
5. **出界管不了**：已发上游、已给用户的数据，回滚不覆盖；合流只对状态成立。
6. **便宜信号优先**：路由/升级/早停/腐烂检测用轻量信号；贵模型只做内容生成。

## 六、12 类上下文盘点

| 类 | 性质 | 落点 |
|---|---|---|
| 语料 | 全量，不进窗口 | retrieval |
| 证据窗口 | 按查询开，答完失效 | qaflow stage 2 |
| 知识簇 | 清单 + 按需展开 | knowledge |
| 会话 | 按轮保留，超限压缩 | qaflow stage 1 |
| 改写 | 当次有效 | qaflow stage 1 |
| 用量台账 | 只增不改 | usage |
| 评测题集 | 不可变版本 | evalfcore |
| 护栏基线 | 只增不改 | learncore |
| 信念 | 可回退版本 | knowledge/belief |
| 冲突边 | 只增，复核后收敛 | knowledge |
| 摄取任务 | 状态机，可续 | ingest |
| 模型配置 | 激活=物化 + 版本记录 | evalfcore / learncore 共用 |

驱逐初始参数（抄自 Volt 论文，**未在本项目语料实测，第一版实测后按数据改本文**）：同类语义去重 0.92；综合分 = 0.4 新近 + 0.3 成功 + 0.2 log 频次 + 0.1 密度；会话类聚类 ≥ 0.85 且 ≥ 3 条合并。

## 七、边界（诚实清单）

- 本文是文法不是实现；每个 stage 的算法细节在各自包的文档。
- 可逆性作用于状态注册；Go 卸不了代码，热插拔 = 换实现 + 记版本（见 ADR-001）。
- 失败六分类与驱逐参数是外部论文的迁移，本项目未验证。
- 学习五阶段的自动化程度是目标，v0.1 只有骨架。
