# 开发经验（截至 2026-10-08，破局链完成后）

这份文档记录 cumulus-next 开发中被真跑反复验证的工程经验。不是设计
文档（设计在 architecture.md 与流程文法），是**什么做法被证明有效、
什么坑被反复踩**的记录。每条都标了它是在哪次真跑里长出来的。

## 一、纪律类：三条老坑，各踩三次以上

**1. 禁闭纪律是最值钱的 bug 捕获器。** context 的键写了不申报，stage
结束即蒸发——prior 开关全程静默（窗口分数还是旧径的）、deep 回填的窗
口全程无标题、事实族信号全是 0，三次都是同一形态。规则：新增信号/阶
段/字段时，申报（Writes/Reads）与实现必须同一批提交，缺一次就是一次
静默故障。

**2. 早退吞字段。** gatherSignals 的词汇鸿沟折扣在事实填充之前 return，
稀薄查询（后来任何带语料外词的都算）的信号族全是 0。规则：所有填充
先于所有早退；或者干脆一个 gather 函数不许有早退。

**3. 转换链丢字段。** 窗口 Title 在三条转换链上各蒸发过一次——驱逐的
来回转换、deep 的 Hit→Window、bm25 适配链。规则：新字段必须有一条穿
越全部转换的端到端测试，只测生产侧不够。

## 二、测试类：夹具不像生产，测的就是错东西

**4. 语料夹具的形态决定测试的有效性。** 单文档语料里每个词 df=1，
稀有度加权失去区分度（锚点退化）；8 条同形条文把密度窗口吸错位置。
夹具必须复刻真语料的统计形态（多文档、条文各异、高频词真的高频），
否则测出来的是夹具的性质不是系统的性质。

**5. 契约测试要覆盖"合法的坏输出"。** 模型 outputs 零断言答案、编造
引用标签、带断言的拒答——都是格式合法但语义违约的输出。每一条都要有
测试钉死系统的反应（转诚实拒答，不是 500）。

## 三、词面方法的天花板是具体的

**6. 3 字核心规则认不出改写。** "期限是多少年"对"发明专利权的期限为
二十年"——事实与法条没有共享的 3 字连续片段，核心判据全落空。绕过方
法是内容词齐聚锚（不要求连续，要求内容词在半径内全部命中）；正解是
LLM 事实感知评分（cumulus 的 FactAware 之路）。**知道词面在哪里停、
模型该在哪里接，本身是设计能力**——硬用词面补语义，补出来的都是靶
向特定夹具的补丁。

**7. 稀有度是语料相关的，不能当锚点。** 真实法条语料里"专利"比"期
限"稀有（前者 df≈30，后者 df≈200），稀有度锚点把窗口放在"授予专利权
决定"那条，答案在第四十二条。锚点必须由**事实自己的内容**决定，不能
由语料统计独断。

## 四、系统行为类

**8. 非确定性要逐链节猎杀。** 一条答案链上的随机源：词汇桥（LLM 扩
展，每次用词不同）→ 缓存后稳定；复用库（同 session 第二问起 hit）；
检索/弃权头/事实判定（确定性）。剩下合成本身——那是 LLM 的天性，由
复用库兜底。猎不干净的随机源会伪装成"模型不稳定"，实际是工程没做完。

**9. 契约违例降级为一等公民拒答，不是错误。** 模型一定会在某个时刻
违反引用契约。系统的正确反应是 refused + 原话理由，让用户看到诚实的
不确定；500 是把系统的严苛转嫁成用户的困惑。

**10. 论文要先有自己的诊断再读。** SUBQRAG（子问题链逐条检索）与
Noesis（7B 以下瓶颈是上下文利用→两层上下文）两次直接改设计——但都
是在我们用自己的真跑诊断出"多事实问句丢证据""平铺证据里模型丢失事
实归属"之后，论文才指得动路。没有自己的诊断，论文只是目录。

## 五、方向类

**11. 真实使用胜过基准数字。** 这一轮所有真正的质量跃升——词汇鸿沟
桥、窗口定心、prior、逐事实取证据链——没有一次来自评测分数提升，全
部来自真实问句的答不对（闯红灯、专利两连问）。88% 的评测数字一次都
没有预测到这些失败。基准是回归护栏，不是方向；方向从真实使用里来。

**12. "数字迷途"是真实存在的引力。** 中期曾经连续多轮在跑分上加
臂、加轮次，指标动 0.几个点，与"答得准不准"的体感脱节。用户的纠
正——不陷入数字迷途，以最通透的思维架构解决问题——之后，每一轮的
判据变成了"这一件让哪个真实问题消失了"。
